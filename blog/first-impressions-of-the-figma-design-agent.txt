                    <h1 id="figma-design-agent-初体验">
                        <a href="#figma-design-agent-初体验">Figma design agent 初体验</a>
                    </h1>
                <p>总体感受：慢！很慢！非常慢！但还是有用的，上升空间很大。</p>
<p>测试案例：</p>
<ul>
<li>给组件库做标注</li>
<li>还原矢量图标</li>
<li>回答变量库迁移问题</li>
<li>生成图表</li>
<li>拆分&amp;嵌套组件集</li>
</ul>

                    <h3 id="1-给组件库做标注">
                        <a href="#1-给组件库做标注">1. 给组件库做标注</a>
                    </h3>
                <p>标注的内容比较完整、易读，但很慢，而且标注严重错位，还好标注打了组，手动移到正确的位置也很快。
当然错位问题也可以反馈给 AI 让它自己改，就是也很慢。</p>
<p><img src="../assests/blog/image/add-annotations.png" alt="给组件添加标注"></p>

                    <h3 id="2-还原矢量图标">
                        <a href="#2-还原矢量图标">2. 还原矢量图标</a>
                    </h3>
                <p>未指定生成矢量图时，会默认生成位图，能生成很精美的位图，但不是我需要的。
指定生成矢量图后，会与市面上大多数位图转矢量图一样，沿着像素生成复杂路径，没有可编辑性，也不是我需要的。
指定分析线条、填充后再绘制，能生成简单的图形组合，部分元素能用。
在这方面还需要大量训练。</p>
<p><img src="../assests/blog/image/design-vector-icon.png" alt="生成矢量图标"></p>

                    <h3 id="3-回答变量库迁移问题">
                        <a href="#3-回答变量库迁移问题">3. 回答变量库迁移问题</a>
                    </h3>
                <p>能很快给出解决方案。</p>
<p><img src="../assests/blog/image/variable-migration.png" alt="回答变量库迁移问题"></p>

                    <h3 id="4-生成图表">
                        <a href="#4-生成图表">4. 生成图表</a>
                    </h3>
                <p>图表整体结构正确，会出现箭头方向不对，文字错位的问题。手动修改比较快。</p>
<p><img src="../assests/blog/image/variable-migration-diagram.png" alt="生成图表"></p>

                    <h3 id="5-拆分amp嵌套组件集">
                        <a href="#5-拆分amp嵌套组件集">5. 拆分&amp;嵌套组件集</a>
                    </h3>
                <p>测试了修改 <a href="https://www.figma.com/community/file/1574139834768289607/ant-design-system-v6?q_id=982b3ca3-5863-4950-8a94-096f938714fe">AntUIKit</a> 的 Button 组件集，比手动操作快多了，但层级过多，还没有达到精简变体的效果。需要后续理清想要的嵌套结构，再让 agent 进一步修改。</p>
<p><img src="../assests/blog/image/restructure-components.png" alt="重构组件层级"></p>
