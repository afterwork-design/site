                    <h1 id="figma-agent-笔记">
                        <a href="#figma-agent-笔记">Figma Agent 笔记</a>
                    </h1>
                
                    <h2 id="视频-meet-the-figma-design-agent">
                        <a href="#视频-meet-the-figma-design-agent">视频 - Meet the Figma design agent</a>
                    </h2>
                <blockquote>
<p><a href="https://www.youtube.com/watch?v=vY5IoRVTnJs">https://www.youtube.com/watch?v=vY5IoRVTnJs</a></p>
</blockquote>
<p>Figma Agent 是一个嵌入设计工具中的 AI 助手，能自动化重复性任务、加速设计探索、维护设计规范、辅助团队协作，让设计师专注于真正有创造性的工作。</p>
<p>此视频是 Figma 产品经理 Rodrigo 和产品设计师 Tammy 介绍 Figma 新推出的 <strong>Agent（智能代理）</strong> 功能。</p>

                    <h3 id="一核心价值解决重复性工作">
                        <a href="#一核心价值解决重复性工作">一、核心价值：解决重复性工作</a>
                    </h3>
                <p>Agent 主要帮助设计师处理那些<strong>耗时、繁琐且打断创作流程</strong>的任务：</p>
<ul>
<li>批量替换组件、修改间距等重复性编辑（可跨 <strong>30 个屏幕</strong>批量操作）</li>
<li>批量填充真实内容（用户评论、头像、图片等）</li>
<li>只需一次修改提示框，即可自动应用到所有相关屏幕，<strong>节省 15-30 分钟</strong></li>
</ul>

                    <h3 id="二核心功能">
                        <a href="#二核心功能">二、核心功能</a>
                    </h3>
                
                    <h4 id="并行探索设计方向">
                        <a href="#并行探索设计方向">并行探索设计方向</a>
                    </h4>
                <ul>
<li>可选择单个节点、多个父框架，或探索整个画布</li>
<li>Agent <strong>实时在画布上工作</strong>，你可以边看边调整</li>
</ul>

                    <h4 id="设计库维护">
                        <a href="#设计库维护">设计库维护</a>
                    </h4>
                <ul>
<li>统一命名规范</li>
<li>更新旧版/不符合品牌的 Token</li>
<li>创建使用指南</li>
</ul>

                    <h4 id="ai-直接操作结合">
                        <a href="#ai-直接操作结合">AI + 直接操作结合</a>
                    </h4>
                <ul>
<li>快速生成设计起点（全新屏幕或修改现有设计）</li>
<li><strong>混搭重混</strong>现有设计，尝试不同布局</li>
<li>探索更大胆、更有创意的方向</li>
</ul>

                    <h4 id="关联设计库生成">
                        <a href="#关联设计库生成">关联设计库生成</a>
                    </h4>
                <ul>
<li>生成屏幕时可<strong>自动使用已关联的设计库</strong></li>
<li>Agent 根据上下文自动选择正确的组件和 Token</li>
<li>可通过 <code>@提及</code> 指定具体组件</li>
</ul>

                    <h4 id="协作与评论管理">
                        <a href="#协作与评论管理">协作与评论管理</a>
                    </h4>
                <ul>
<li>按主题/话题<strong>汇总评论</strong></li>
<li>解释不清楚的评论</li>
<li>自动<strong>初步处理</strong>单个评论或整类主题</li>
</ul>

                    <h3 id="三未来规划">
                        <a href="#三未来规划">三、未来规划</a>
                    </h3>
                <ul>
<li>Agent 将获得更多上下文感知（附件、其他工具、互联网）</li>
<li>支持用户自定义 Agent 行为</li>
<li><strong>逐步灰度上线</strong>，确保稳定性和高质量</li>
</ul>
<hr>

                    <h2 id="文档-work-with-the-figma-agent-in-design-files">
                        <a href="#文档-work-with-the-figma-agent-in-design-files">文档 - Work with the Figma agent in design files</a>
                    </h2>
                <blockquote>
<p><a href="https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-AI-agent-in-Figma-Design">https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-AI-agent-in-Figma-Design</a></p>
</blockquote>
<p>本文档为 Figma 官方帮助指南，主要介绍了在 <a href="https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-Figma-agent-in-design-files">Figma Design</a> 中使用 <strong>Figma Agent（AI 智能体）</strong> 的功能、操作方式及常见问题。</p>
<p><strong>一、 主要功能与用途</strong></p>
<ul>
<li><strong>生成与改造设计：</strong> 从零生成页面布局（0→1 Generation）、重构版面、修改 Layout 与 组件实例（Variants/Properties）。</li>
<li><strong>自动化繁琐任务：</strong> 批量生成真实填充数据、重命名图层（Rename Layers）、文本翻译/重写、批量替换图片等。</li>
<li><strong>设计系统联动：</strong> 关联组件库（Library），使用 <code>@</code> 直接引用特定的组件、变量（Variables）和样式（Styles）。</li>
<li><strong>高级特效与扩展：</strong> 制作着色器（Shaders）、添加动态/动画（Motion）、通过 MCP 连接器对接外部工具，甚至自动生成专属插件。</li>
<li><strong>设计反馈与问答：</strong> 提供无障碍评审、多角色视角（如新用户或产品 VP）的设计批评，并能直接解答 Figma 使用问题。</li>
</ul>
<p><strong>二、 如何开启与使用</strong></p>
<ul>
<li><strong>快捷开启：</strong> 选中画布上的任意图层后点击 <strong>Agents</strong>，或使用快捷键 <code>Cmd/Ctrl + Enter</code>；也可在左侧导航栏打开 Agent 侧边栏进行持续对话。</li>
<li><strong>并行任务处理：</strong> 支持同时运行多个 Prompt，无需等待上一个任务完成即可开始下一个。</li>
<li><strong>撤销与对比：</strong> 支持通过聊天框内的 <strong>Undo</strong> 或快捷键 <code>Cmd/Ctrl + Z</code> 随时撤销 Agent 所做的更改。</li>
</ul>
<p><strong>三、 不同 AI 工具的区别</strong></p>
<ul>
<li><strong>Figma Agent：</strong> 驻留在 Figma Design 内，协助进行画布设计、自动化任务与设计评审。</li>
<li><strong>Figma Make：</strong> 专注于生成交互式 App 与原型，并支持发布到 Web 端。</li>
<li><strong>Write to Canvas MCP：</strong> 属于 Figma MCP 服务，用于将外部 AI 编程工具（如 Claude Code、Cursor 等）的代码及内容写入 Figma 文件。</li>
</ul>
