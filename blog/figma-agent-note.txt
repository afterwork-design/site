                    <h1 id="figma-agent-笔记">
                        <a href="#figma-agent-笔记">Figma Agent 笔记</a>
                    </h1>
                
                    <h2 id="视频-meet-the-figma-design-agent">
                        <a href="#视频-meet-the-figma-design-agent">视频 - Meet the Figma design agent</a>
                    </h2>
                <blockquote>
<p><a href="https://www.youtube.com/watch?v=vY5IoRVTnJs">https://www.youtube.com/watch?v=vY5IoRVTnJs</a></p>
</blockquote>
<p>Figma 产品经理 Rodrigo 和产品设计师 Tammy 介绍 Figma 新推出的 <strong>Agent（智能代理）</strong> 功能。</p>

                    <h3 id="一核心价值解决重复性工作">
                        <a href="#一核心价值解决重复性工作">一、核心价值：解决重复性工作</a>
                    </h3>
                <p>Agent 主要帮助设计师处理那些<strong>耗时、繁琐且打断创作流程</strong>的任务：</p>
<ul>
<li>批量替换组件、修改间距等重复性编辑（可跨 <strong>30 个屏幕</strong>批量操作）</li>
<li>批量填充真实内容（用户评论、头像、图片等）</li>
<li>只需一次修改提示框，即可自动应用到所有相关屏幕，<strong>节省 15-30 分钟</strong></li>
</ul>

                    <h3 id="二核心功能">
                        <a href="#二核心功能">二、核心功能</a>
                    </h3>
                
                    <h4 id="并行探索设计方向">
                        <a href="#并行探索设计方向">并行探索设计方向</a>
                    </h4>
                <ul>
<li>可选择单个节点、多个父框架，或探索整个画布</li>
<li>Agent <strong>实时在画布上工作</strong>，你可以边看边调整</li>
</ul>

                    <h4 id="设计库维护">
                        <a href="#设计库维护">设计库维护</a>
                    </h4>
                <ul>
<li>统一命名规范</li>
<li>更新旧版/不符合品牌的 Token</li>
<li>创建使用指南</li>
</ul>

                    <h4 id="ai-直接操作结合">
                        <a href="#ai-直接操作结合">AI + 直接操作结合</a>
                    </h4>
                <ul>
<li>快速生成设计起点（全新屏幕或修改现有设计）</li>
<li><strong>混搭重混</strong>现有设计，尝试不同布局</li>
<li>探索更大胆、更有创意的方向</li>
</ul>

                    <h4 id="使用设计库生成">
                        <a href="#使用设计库生成">使用设计库生成</a>
                    </h4>
                <ul>
<li>生成屏幕时可<strong>自动使用已关联的设计库</strong></li>
<li>Agent 根据上下文自动选择正确的组件和 Token</li>
<li>可通过 <code>@提及</code> 指定具体组件</li>
</ul>

                    <h4 id="协作与评论管理">
                        <a href="#协作与评论管理">协作与评论管理</a>
                    </h4>
                <ul>
<li>按主题/话题<strong>汇总评论</strong></li>
<li>解释不清楚的评论</li>
<li>自动<strong>初步处理</strong>单个评论或整类主题</li>
</ul>

                    <h3 id="三未来规划">
                        <a href="#三未来规划">三、未来规划</a>
                    </h3>
                <ul>
<li>Agent 将获得更多上下文感知（附件、其他工具、互联网）</li>
<li>支持用户自定义 Agent 行为</li>
<li><strong>逐步灰度上线</strong>，确保稳定性和高质量</li>
</ul>

                    <h3 id="四一句话总结">
                        <a href="#四一句话总结">四、一句话总结</a>
                    </h3>
                <blockquote>
<p><strong>Figma Agent 是一个嵌入设计工具中的 AI 助手，能自动化重复性任务、加速设计探索、维护设计规范、辅助团队协作，让设计师专注于真正有创造性的工作。</strong></p>
</blockquote>

                    <h2 id="文档-work-with-the-figma-agent-in-design-files">
                        <a href="#文档-work-with-the-figma-agent-in-design-files">文档 - Work with the Figma agent in design files</a>
                    </h2>
                <blockquote>
<p><a href="https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-AI-agent-in-Figma-Design">https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-AI-agent-in-Figma-Design</a></p>
</blockquote>
<p>本文档介绍了Figma Design中AI Agent（代理）的功能和使用方法，这是一个在封闭测试阶段对部分用户免费开放的功能。该代理能够帮助设计师生成和混合设计、自动化繁琐工作并获得设计反馈，支持通过画布或侧边栏进行交互，允许并行运行多个提示、连接设计系统库并引用特定组件和变量。文档详细说明了代理支持的功能，如从零生成、编辑布局、批量处理内容和提供设计反馈，并提供了最佳实践建议，包括使用自动布局、提供具体指令和组织聊天线程。</p>

                    <h3 id="关键点">
                        <a href="#关键点">关键点</a>
                    </h3>
                <ul>
<li>AI Agent目前在Figma Design中供Professional、Organization和Enterprise计划的用户试用，具有完全编辑权限的用户可以完整使用。</li>
<li>用户可以通过选择画布上的图层并按<code>Cmd/Ctrl+Enter</code>快捷键，或在左侧导航栏点击Agents，来访问并开始与代理对话。</li>
<li>代理支持在多个帧上并行运行不同的提示，无需等待前一个任务完成，从而加速工作流程。</li>
<li>通过连接Figma文件中的库，代理可以生成符合团队现有组件、样式和变量规范的设计结果。</li>
<li>为获得更精准的输出，用户可以在提示中使用@符号直接引用设计系统中的特定组件、变量和样式。</li>
<li>代理能够回答关于如何使用Figma Design本身的操作性问题，例如“如何使用自动布局？”，其答案来源于Figma帮助中心。</li>
<li>代理提供的一项关键功能是“撤销（Undo）”，用户可以随时撤销代理所做的单次修改，保持对设计决定的完全控制。</li>
<li>代理支持的功能包括从零生成新设计、编辑布局和组件实例、应用样式和变量、批量生成和编辑文本与图片、搜索库、审查评论以及提供设计反馈等。</li>
</ul>
