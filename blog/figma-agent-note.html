Figma Agent 笔记

视频 - Meet the Figma design agent

https://www.youtube.com/watch?v=vY5IoRVTnJs

Figma Agent 是一个嵌入设计工具中的 AI 助手，能自动化重复性任务、加速设计探索、维护设计规范、辅助团队协作，让设计师专注于真正有创造性的工作。

此视频是 Figma 产品经理 Rodrigo 和产品设计师 Tammy 介绍 Figma 新推出的 Agent（智能代理） 功能。

一、核心价值：解决重复性工作

Agent 主要帮助设计师处理那些耗时、繁琐且打断创作流程的任务：

  • 批量替换组件、修改间距等重复性编辑（可跨 30 个屏幕批量操作）
  • 批量填充真实内容（用户评论、头像、图片等）
  • 只需一次修改提示框，即可自动应用到所有相关屏幕，节省 15-30 分钟

二、核心功能

并行探索设计方向

  • 可选择单个节点、多个父框架，或探索整个画布
  • Agent 实时在画布上工作，你可以边看边调整

设计库维护

  • 统一命名规范
  • 更新旧版/不符合品牌的 Token
  • 创建使用指南

AI + 直接操作结合

  • 快速生成设计起点（全新屏幕或修改现有设计）
  • 混搭重混现有设计，尝试不同布局
  • 探索更大胆、更有创意的方向

关联设计库生成

  • 生成屏幕时可自动使用已关联的设计库
  • Agent 根据上下文自动选择正确的组件和 Token
  • 可通过 @提及 指定具体组件

协作与评论管理

  • 按主题/话题汇总评论
  • 解释不清楚的评论
  • 自动初步处理单个评论或整类主题

三、未来规划

  • Agent 将获得更多上下文感知（附件、其他工具、互联网）
  • 支持用户自定义 Agent 行为
  • 逐步灰度上线，确保稳定性和高质量

文档 - Work with the Figma agent in design files

https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-AI-agent-in-Figma-Design

本文档为 Figma 官方帮助指南，主要介绍了在 Figma Design 中使用 Figma Agent（AI 智能体） 的功能、操作方式及常见问题。

一、 主要功能与用途

  • 生成与改造设计： 从零生成页面布局（0→1 Generation）、重构版面、修改 Layout 与 组件实例（Variants/Properties）。
  • 自动化繁琐任务： 批量生成真实填充数据、重命名图层（Rename Layers）、文本翻译/重写、批量替换图片等。
  • 设计系统联动： 关联组件库（Library），使用 @ 直接引用特定的组件、变量（Variables）和样式（Styles）。
  • 高级特效与扩展： 制作着色器（Shaders）、添加动态/动画（Motion）、通过 MCP 连接器对接外部工具，甚至自动生成专属插件。
  • 设计反馈与问答： 提供无障碍评审、多角色视角（如新用户或产品 VP）的设计批评，并能直接解答 Figma 使用问题。

二、 如何开启与使用

  • 快捷开启： 选中画布上的任意图层后点击 Agents，或使用快捷键 Cmd/Ctrl + Enter；也可在左侧导航栏打开 Agent 侧边栏进行持续对话。
  • 并行任务处理： 支持同时运行多个 Prompt，无需等待上一个任务完成即可开始下一个。
  • 撤销与对比： 支持通过聊天框内的 Undo 或快捷键 Cmd/Ctrl + Z 随时撤销 Agent 所做的更改。

三、 不同 AI 工具的区别

  • Figma Agent： 驻留在 Figma Design 内，协助进行画布设计、自动化任务与设计评审。
  • Figma Make： 专注于生成交互式 App 与原型，并支持发布到 Web 端。
  • Write to Canvas MCP： 属于 Figma MCP 服务，用于将外部 AI 编程工具（如 Claude Code、Cursor 等）的代码及内容写入 Figma 文件。
