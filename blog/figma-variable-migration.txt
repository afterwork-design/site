                    <h1 id="figma-跨文件迁移变量的方式">
                        <a href="#figma-跨文件迁移变量的方式">Figma 跨文件迁移变量的方式</a>
                    </h1>
                <p>如果文件 A、B、C 都用了文件 D 的变量，现在想把文件 D 的变量独立到文件 E 中，让文件 A、B、C 以及将来的新文件都用文件 E 中的变量，如何操作？</p>
<p><img src="../assests/blog/image/variable-migration-diagram.png" alt="variable-migration-diagram"></p>

                    <h2 id="第一步将变量迁移到文件-e">
                        <a href="#第一步将变量迁移到文件-e">第一步：将变量迁移到文件 E</a>
                    </h2>
                
                    <h3 id="方式1复制粘贴">
                        <a href="#方式1复制粘贴">方式1：复制、粘贴</a>
                    </h3>
                <p>这是 Figma 原生功能，但有限制，复制粘贴变量不会保留分组结构，需要手动重建。适合无分组的变量迁移。</p>
<ol>
<li>打开文件 D，进入变量集合</li>
<li>全选变量 → 右键 <code>Copy</code></li>
<li>打开文件 E，创建同名的变量集合</li>
<li>右键 <code>Paste</code>，将变量粘贴进来</li>
<li>将文件 E 发布为共享库</li>
</ol>

                    <h3 id="方式2导出导入">
                        <a href="#方式2导出导入">方式2：导出、导入</a>
                    </h3>
                <p> Figma 原生功能，也有限制，导出的文件是按 mode 拆分的，适合有分组且只有一个 mode 的变量迁移。</p>
<ol>
<li>打开文件 D，进入变量集合</li>
<li>选择变量集合 → 右键 <code>Export modes</code></li>
<li>解压导出的变量 json 文件</li>
<li>打开文件 E，创建同名的变量集合</li>
<li>点击 <code>Import</code>，将变量文件导入进来</li>
<li>将文件 E 发布为共享库</li>
</ol>

                    <h3 id="方式3用插件">
                        <a href="#方式3用插件">方式3：用插件</a>
                    </h3>
                <p>最完整的迁移方案，适合含分组、多集合、多 Mode 的变量。可尝试的社区插件：</p>
<ul>
<li><strong>Variables Import Export</strong></li>
<li><strong>Token Flow</strong></li>
<li><strong>Tokens Studio</strong></li>
</ul>
<p>这类插件可以导出包含完整结构的 JSON，再导入到文件 E。</p>

                    <h2 id="第二步在文件-abc-中替换库引用（swap-library）">
                        <a href="#第二步在文件-abc-中替换库引用（swap-library）">第二步：在文件 A、B、C 中替换库引用（Swap Library）</a>
                    </h2>
                <p>对每个消费文件（A、B、C）分别执行：</p>
<ol>
<li>打开该文件，点击 <code>Assets</code> 面板</li>
<li>点击右上角 <code>Libraries</code></li>
<li>找到文件 D 的库，点击进入详情页</li>
<li>点击右下角 <code>Swap library</code>，选择文件 E 作为替换目标</li>
<li>Figma 会自动按名称匹配变量，确认映射关系后点击<code>Swap library</code></li>
</ol>

                    <h2 id="关键注意事项">
                        <a href="#关键注意事项">关键注意事项</a>
                    </h2>
                <ul>
<li><strong>变量名称必须一致</strong>：Swap Library 是按名称匹配的，文件 E 中的变量名要和文件 D 完全相同，否则无法自动映射</li>
<li><strong>集合名称也要一致</strong>：集合名不同会导致匹配失败</li>
<li><strong>逐文件操作</strong>：每个消费文件都需要单独执行 Swap Library</li>
<li><strong>迁移完成后</strong>：可以停用或删除文件 D 的变量库，新文件直接订阅文件 E 的库即可</li>
</ul>
