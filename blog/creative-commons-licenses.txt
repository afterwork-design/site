                    <h1 id="creative-commons-cc-协议详解与实例">
                        <a href="#creative-commons-cc-协议详解与实例">Creative Commons (CC) 协议详解与实例</a>
                    </h1>
                <p>知识共享许可协议（Creative Commons licenses，简称CC协议）是一套全球通用的标准化版权许可工具，它帮助创作者在“保留所有权利”的传统版权和“不保留任何权利”的公共领域之间，找到“保留部分权利”的中间道路。其核心逻辑是由<strong>署名（BY）</strong>、<strong>非商业性使用（NC）</strong>、<strong>禁止演绎（ND）</strong>、<strong>相同方式共享（SA）</strong> 这四个核心要素组合成六种常用的协议。</p>

                    <h2 id="一四个核心要素">
                        <a href="#一四个核心要素">一、四个核心要素</a>
                    </h2>
                <ul>
<li><p><strong>BY (Attribution) —— 署名</strong><br>缩写来源于英文单词 <strong>&quot;by&quot;</strong>（意为“由……创作”）。使用者可以复制、发行、展览、表演、放映、广播或通过信息网络传播作品，但<strong>必须保留原作者的署名</strong>。这是所有CC协议都必须包含的基础要素。</p>
</li>
<li><p><strong>ND (No Derivative Works) —— 禁止演绎</strong><br>缩写来源于英文 <strong>&quot;No Derivative Works&quot;</strong>。使用者可以原样复制、分发作品，但<strong>不得修改、转变或基于本作品进行任何再创作</strong>。即必须原样使用，不能改编。</p>
</li>
<li><p><strong>NC (Noncommercial) —— 非商业性使用</strong><br>缩写来源于英文 <strong>&quot;Noncommercial&quot;</strong>。使用者可以复制、发行、展览、表演等，但<strong>不得为获得商业优势或金钱报酬而使用</strong>。</p>
</li>
<li><p><strong>SA (Share Alike) —— 相同方式共享</strong><br>缩写来源于英文 <strong>&quot;Share Alike&quot;</strong>。使用者可以修改、转变或基于本作品进行再创作，但<strong>仅当以与本作品相同的许可协议发布衍生作品时</strong>，才被允许分发该衍生作品。这也被称为“Copyleft”条款。</p>
</li>
</ul>

                    <h2 id="二六种主要cc协议详解">
                        <a href="#二六种主要cc协议详解">二、六种主要CC协议详解</a>
                    </h2>
                <p>以下按授权自由度从高到低排列：</p>
<table>
<thead>
<tr>
<th align="left">协议名称</th>
<th align="left">协议要素</th>
<th align="left">核心条件</th>
<th align="left">特点与适用场景</th>
</tr>
</thead>

<td align="left"><strong>CC BY<br>（署名）</strong></td>
<td align="left">BY</td>
<td align="left">使用者可以<strong>任何形式、任何目的</strong>（含商业目的）复制、发行、修改作品，唯需署名原作者。</td>
<td align="left"><strong>最宽松的协议</strong>。允许对作品进行几乎任何形式的使用，包括修改和商用。适用于希望作品获得最广泛传播的创作者，如学术论文。</td>
</tr>
<tr>
<td align="left"><strong>CC BY-SA<br>（署名-相同方式共享）</strong></td>
<td align="left">BY, SA</td>

<td align="left">确保所有衍生品都保持同样的开放度，有“传染性”。<strong>维基百科</strong>采用此协议。适合希望作品及其演绎版本都保持开放的创作者。</td>

<td align="left">BY, ND</td>
<td align="left">使用者可以<strong>任何目的</strong>（含商业目的）<strong>原样复制、分发</strong>作品，<strong>必须署名</strong>，但<strong>不得修改或创作衍生作品</strong>。允许个人私下修改，但不可公开分享修改版。</td>
<td align="left">保证作品的<strong>完整性</strong>。适合不希望作品被修改的创作者，如演讲录像、官方声明等。</td>
</tr>
<tr>
<td align="left"><strong>CC BY-NC<br>（署名-非商业性使用）</strong></td>
<td align="left">BY, NC</td>
<td align="left">使用者可以修改、再创作作品，但<strong>只能用于非商业目的</strong>，且<strong>必须署名</strong>。对衍生作品的许可方式没有限制。</td>
<td align="left">允许他人以非商业目的改编你的作品，但对改编后的作品如何授权无限制。适用于希望作品被广泛非商用改编的创作者。</td>
</tr>
<tr>
<td align="left"><strong>CC BY-NC-SA<br>（署名-非商业性使用-相同方式共享）</strong></td>
<td align="left">BY, NC, SA</td>
<td align="left">使用者可以修改、再创作作品，但<strong>只能用于非商业目的</strong>，且<strong>必须署名</strong>。同时，<strong>衍生作品必须采用相同的许可协议</strong>（CC BY-NC-SA）。</td>
<td align="left"><strong>最严格的非商业性许可协议</strong>之一。在禁止商业使用的同时，也通过“相同方式共享”确保衍生作品同样保持非商业的开放精神。</td>
</tr>
<tr>
<td align="left"><strong>CC BY-NC-ND<br>（署名-非商业性使用-禁止演绎）</strong></td>
<td align="left">BY, NC, ND</td>
<td align="left">使用者只能<strong>原样复制、分发</strong>作品，<strong>不得用于商业目的</strong>，且<strong>必须署名</strong>。<strong>禁止任何形式的修改和创作衍生品</strong>。允许个人私下修改，但不可公开分享。</td>
<td align="left"><strong>最具限制性的协议</strong>。使用者只能原封不动地非商业性分享作品。适合只想让作品被原样、非商业传播的创作者。</td>
</tr>
</tbody></table>

                    <h2 id="三两个特别概念">
                        <a href="#三两个特别概念">三、两个特别概念</a>
                    </h2>
                <ul>
<li><p><strong>CC0 公共领域贡献工具</strong><br>这并不是一份许可协议，而是一个法律工具。创作者通过它<strong>放弃所有版权</strong>及相关权利，将作品完全置于<strong>公共领域</strong>。任何人可以任何目的使用作品，无需署名，也无需取得许可。</p>
</li>
<li><p><strong>协议版本</strong><br>CC协议有多个版本，目前的最新国际通用版本是 <strong>4.0版</strong>。该版本具有通用性，无需本地化即可在全球使用。</p>
</li>
</ul>

                    <h2 id="四如何选择适合你的cc协议——实例参考">
                        <a href="#四如何选择适合你的cc协议——实例参考">四、如何选择适合你的CC协议？——实例参考</a>
                    </h2>
                <p>选择哪种协议，最终取决于你希望他人如何分享和使用你的作品。你可以通过回答以下两个问题来缩小范围：</p>
<ol>
<li><p><strong>我介意别人对我的作品进行商业性使用吗？</strong></p>
<ul>
<li>如果介意，你的协议中需要包含 <strong>NC</strong>（非商业性使用）。</li>
<li>如果不介意，则排除 NC。</li>
</ul>
</li>
<li><p><strong>我允许别人修改或改编我的作品吗？</strong></p>
<ul>
<li>如果不允许，你的协议中需要包含 <strong>ND</strong>（禁止演绎）。</li>
<li>如果允许，再问：<strong>我需要他们以同样的方式共享吗？</strong><ul>
<li>如果需要，加入 <strong>SA</strong>（相同方式共享）。</li>
<li>如果不需要，则只保留 <strong>BY</strong>（署名）。</li>
</ul>
</li>
</ul>
</li>
</ol>
<p>根据你的答案，就可以在上述六种协议中找到最匹配的那一款。下面的实例将帮助你更直观地理解这些选择在实际中的应用。</p>

                    <h3 id="📚-文字与教育类">
                        <a href="#📚-文字与教育类">📚 文字与教育类</a>
                    </h3>
                <ul>
<li><p><strong>维基百科</strong>：<strong>CC BY-SA</strong><br>确保任何人修改或扩充内容后，也必须以同样的自由协议分享，保证知识库始终开放。</p>
</li>
<li><p><strong>学术论文（开放获取期刊）</strong>：<strong>CC BY</strong><br>最开放，允许任何人翻译、分析、构建论文内容，甚至用于商业目的，只要正确署名，加速科学研究进展。</p>
</li>
<li><p><strong>中小学教案与课件</strong>：<strong>CC BY-NC-SA</strong><br>允许其他老师非商业性修改使用，但禁止商业化（如印成辅导书卖钱），且修改后的作品也必须以同样方式分享。</p>
</li>
</ul>

                    <h3 id="🎨-图片与摄影类">
                        <a href="#🎨-图片与摄影类">🎨 图片与摄影类</a>
                    </h3>
                <ul>
<li><p><strong>免费图库网站（如Pixabay、Unsplash）</strong>：<strong>CC0</strong><br>用户可免费下载、修改、商用，无需署名，对设计师和商业用户最友好。</p>
</li>
<li><p><strong>Flickr上的CC BY图片</strong>：<strong>CC BY</strong><br>摄影师允许别人使用（包括商用），但必须署名，获得传播与署名权。</p>
</li>
<li><p><strong>艺术家的个人作品集</strong>：<strong>CC BY-ND</strong><br>希望作品被广泛分享传播（署名），但禁止他人篡改（如P图、截取），保护作品完整性。</p>
</li>
</ul>

                    <h3 id="🎬-音频与视频类">
                        <a href="#🎬-音频与视频类">🎬 音频与视频类</a>
                    </h3>
                <ul>
<li><p><strong>播客节目背景音乐</strong>：<strong>CC BY-NC-ND</strong><br>允许用作背景音乐，但禁止商业使用（NC），且禁止对音乐进行截取、混音（ND），保持音乐完整性。</p>
</li>
<li><p><strong>TED演讲视频</strong>：<strong>CC BY-NC-ND</strong><br>允许非商业性分享（NC），必须署名（BY），但禁止剪辑篡改（ND），保证演讲内容严谨性。</p>
</li>
<li><p><strong>音乐混音社区</strong>：<strong>CC BY-NC-SA</strong><br>允许在社区内非商业性改编创作新歌，但新歌也必须以同样协议开放，形成创作链条。</p>
</li>
</ul>

                    <h3 id="💻-其他数字内容">
                        <a href="#💻-其他数字内容">💻 其他数字内容</a>
                    </h3>
                <ul>
<li><p><strong>软件源代码</strong>：通常<strong>不使用</strong>CC协议，而是使用专门的开源许可证如GPL、MIT、Apache等。CC协议不适用于代码。</p>
</li>
<li><p><strong>3D打印模型</strong>：<strong>CC BY-NC</strong><br>允许玩家下载打印、修改模型，但禁止他人批量生产后售卖（NC），保护设计师的劳动成果。</p>
</li>
<li><p><strong>政府发布的公开数据</strong>：<strong>CC BY</strong> 或 <strong>CC0</strong><br>最大限度地促进创新，企业可利用数据分析市场、开发APP，无需复杂授权。</p>
</li>
</ul>
